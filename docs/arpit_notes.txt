To run on a new task:
0. Need a bddl file saved at: bddl/bddl/activity_definition 
1. Environment Interface class to be implemented for your simulation framework (usually a base class) -> This is done
2. Class for the new task (a subclass of the base class) -> Need to implemented (mimicgen/env_interfaces/omnigibson.py)
3. Taks configs: (mimicgen/configs/omnigibson.py)
4. Generate data gen configs: (python mimicgen/scripts/generate_core_configs_og.py)
5. Edit generate_core_configs_og.py
